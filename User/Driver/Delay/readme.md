# 延时模块使用文档

## 模块概述

本模块提供了一套基于 STM32 HAL 库的高精度延时函数，旨在满足对时间敏感的应用需求。所有函数均采用内联优化，确保极致的性能表现。

## 核心注意事项

### 性能优化设计

1. **函数调用开销优化**
    - 为减小函数调用开销，该模块所有函数均为内联形式
    - 所有函数使用 `inline` 关键字定义，避免函数调用的栈操作开销
2. **运行时开销优化**
    - 频率、时钟通道等配置不会随 CubeMX 中的配置修改
    - 关键参数被定义为 `constexpr` 常量，以便编译时直接求解

## 模块配置

### 必要配置项

在 delay.hpp 中需要配置的常量
```C++
constexpr uint32_t FREQ_MHZ = 1; // 时钟频率(MHz)
constexpr TIM_HandleTypeDef* DELAY_HANDLE = &htim13; // 定时器句柄
```

### 配置说明

- `FREQ_MHZ`：TIM经过预分频器(PSC)后的频率，单位为MHz
- `DELAY_HANDLE`：指向使用的定时器句柄
- <span style="color: #ffff00">若用户修改 CubeMX 配置，必须手动修改 `DELAY_HANDLE` 和 `FREQ_MHZ` 的值</span>
- <span style="color: #ffff00">重载计数器(ARR)必须为65535</span>

## 函数功能说明

| 函数名                        | 功能简述                             | 典型用法                                             |
|:---------------------------|:---------------------------------|:-------------------------------------------------|
| **`Init`**                 | **初始化**：启动底层定时器，准备开始计时。          | 在 `main` 函数初始化阶段调用一次。                            |
| **`Delay_us`**             | **微秒级阻塞延时**：执行指定微秒数的延时。          | `Delay::Delay_us(1000);` // 延时 1000 微秒           |
| **`Delay_ms`**             | **毫秒级阻塞延时**：执行指定毫秒数的延时。          | `Delay::Delay_ms(500);` // 延时 500 毫秒             |
| **`DelayUntil_us`**        | **精准周期延时**：维持固定的时间间隔，自动补偿代码执行耗时。 | 配合时间戳变量使用，确保循环周期稳定。                              |
| **`GetTimeStamp`**         | **获取时间戳**：读取当前底层定时器的计数值。         | 用于计算函数执行时间(一般只是调试时用)                             |
| **`CalculateInterval_us`** | **计算时间间隔**：根据起始时间戳计算经过的微秒数。      | `float dt = Delay::CalculateInterval_us(start);` |

## 详细技术说明

### 性能优势

- **零函数调用开销**：所有函数均为内联，编译时直接展开
- **无运行时配置**：关键参数编译时确定，避免运行时查询
- **高精度定时**：基于硬件定时器，长期精度可达100ppm(<10us/s)

### 使用限制

- **配置耦合**：与硬件配置强耦合，修改后需同步更新常量
- **资源占用**：占用一个硬件定时器资源
- **实时性要求**：适用于对实时性要求较高的场景

### 最佳实践

1. **初始化时机**：在系统初始化阶段尽早调用 `Init()`
2. **配置同步**：CubeMX配置变更后立即更新相关常量
3. **资源管理**：确保定时器资源不被其他模块占用

### 简单示例

``` C++
#include "delay.hpp"

int main(void) 
{
    MX_Main_Init(); // CubeMX的初始化函数(不包含调度器部分)    
    Delay::Init(); // 初始化延时模块
    
    while (1) 
    {
        Delay::Delay_ms(500);
    }
}
```
